# Referencia de armado en madera — Video + WoODT

Fuente pedida por el usuario: **"DIY Virtuix Omni-Directional Treadmill Build Log"** (YouTube `oi5DU2JfRhU`, 2015) y el proyecto hermano **WoODT (Wooden Omni Directional Treadmill)** de movesilently.de — el build en madera mejor documentado.

> No pude extraer fotogramas del video directamente, pero recuperé el método de construcción del proyecto WoODT asociado, que es la referencia canónica del armado en madera.

## Hallazgos clave (validan nuestro diseño)

1. **El cuenco es un OCTÁGONO de 8 módulos.** La forma de "sartén"/dish se arma en **8 módulos** (gajos) independientes que se unen en octágono. → Responde tu pregunta: **sí, un octágono de madera es la forma correcta y probada.**
2. **Superficie curva = varias capas de contrachapado fino pegadas** sobre la estructura de soporte de cada módulo (laminado sobre las costillas). Es exactamente nuestro enfoque costillas + piel.
3. **Aro de acero soldado**, pintado, fijado a una **base de madera** para dar estabilidad y proteger el piso. → Coincide con nuestro aro estructural + base + lastre.
4. Permite **caminar, correr, agacharse y sentarse** — el rango de movimiento objetivo.

## Cómo esto cambia el diseño OpenOmni

- **Cuenco por módulos (octágono):** en vez de cortar un anillo circular perfecto, se construyen **8 gajos de 45°** idénticos. Cada gajo = 2 costillas laterales (perfil parabólico) + travesaños + **piel de contrachapado fino laminado en 2–3 capas** (se curva sola al pegarla sobre las costillas). Ventajas: cortes rectos, fácil de transportar, se atornillan entre sí formando el octágono.
- **Superficie deslizante** encima del laminado (HDPE/hardboard sellado + silicona), igual que antes.
- **Aro perimetral octagonal** de fierro (8 tramos rectos soldados/atornillados) sobre **base de madera** con el lastre.

Esto **simplifica el corte** (todo son 8 piezas iguales) y es lo que el modelo 3D y la webapp ahora representan como octágono.
